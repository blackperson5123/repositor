# Правила работы в проекте
## Workflow
- Все изменения вносятся через Pull Request
- Запрещен прямой push в dev и main
## Ветки
- feature/<название_задачи>
- feature/task#<номер_задачи>_<описание>
## Коммиты
task#<номер>: <описание изменений>
## Ревью
- Перед слиянием обязателен ревью от минимум одного участника
